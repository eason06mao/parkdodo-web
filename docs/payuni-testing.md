# 統一金流（PAYUNi）測試區測試方式

來源：統一金流《UPP 整合式支付頁 Ver 2.0》「測試區信用卡測試卡號」一節。測試前先看這份，不要用其他金流的測試卡。

## 測試卡號（只在測試區有效）
| 用途 | 卡號 | 預期結果 |
|---|---|---|
| 信用卡一次付清 | 4147 6310 0000 0001、3560 5110 0000 0001 | 授權成功 |
| 模擬 3D 驗證失敗 | 4147 6310 0000 0002、3560 5110 0000 0002 | 授權失敗（測試失敗頁、不放行） |
| 分期付款 | 4147 6320 0000 0001、3560 5120 0000 0001（不支援 9 期） | 停車繳費未開分期 |
| 銀聯卡 | 6200 0000 0000 0001 | 授權成功 |

- 到期日、背面末三碼可任意填入（例如 12/30、123）
- Apple Pay、Google Pay、Samsung Pay：測試區不限卡號，皆模擬成功
- LINE Pay：測試區開通時，Channel ID 與 Channel Secret Key 可填任意數字（正式區要向 LINE Pay 申請合作商店取得）
- 其他金流（綠界、藍新）的測試卡號，例如 4000 2211 1111 1111，在統一金流測試區會「授權失敗」

## 付款方式要和商店後台一致
繳費頁與付款頁顯示的方式由 GitHub 變數 `PAYUNI_METHODS` 決定（未設定時：信用卡、Apple Pay、Google Pay）。
只能列商店後台已「啟用」的方式，例如 `Credit,ApplePay,GooglePay,SamsungPay,LinePay,JKoPay`。
可用名稱（UPP Ver 2.0 參數）：Credit、CreditUnionPay（銀聯）、ApplePay、GooglePay、SamsungPay、LinePay、JKoPay、ICash。ATM、CVS 刻意不開（入帳慢，車主不能在出口等）。

## 付款後自動開閘（工控機模擬器）
1. 模擬器 http://localhost:8787 選出口車道、輸入車牌，按「模擬辨識到車牌」→ 日誌出現請繳費
2. 5 分鐘內在繳費頁付款（測試卡 4147 6310 0000 0001）
3. 不按任何東西，日誌應出現「已付款，開閘」
4. 按「模擬雷達：車輛通過」
