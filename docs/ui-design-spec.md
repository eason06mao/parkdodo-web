# ParkDodo 後台 UI 設計規格（給開發者）

版本：UI-F_20261019
對應設計稿：《ParkDodo 停車管理系統改版》八個畫面
樣式檔：`src/styles/parkdodo-ui.css`（原生 CSS，所有元件以 `pd-` 為前綴）

## 0. 實作規則

1. 以 HTML5 語意標籤實作：`<nav>`、`<main>`、`<section>`、`<table>`、`<dialog>`、`<button>`、`<label>`。可點擊的東西一律是 `<button>` 或 `<a href>`，不要在 `<div>` 上綁 click。
2. 顏色、字級、間距、圓角一律使用 `parkdodo-ui.css` 的 CSS 變數，不得在元件內寫死色碼。
3. 先引入 `src/styles/parkdodo-ui.css`，再寫頁面專屬樣式。沿用現有前端框架（Next.js app router），不另外引入 UI 套件。
4. 全站只有一個重點色（青綠 `--pd-accent`）。琥珀與紅色只用於「需要注意」與「緊急」，不可當裝飾。
5. 車牌、時間、金額、數量一律用等寬字（`.pd-mono`／`.pd-plate`），方便對齊與比對。
6. 所有互動元件高度至少 44px，手機主要按鈕 52px。
7. 介面語言為繁體中文、台灣用語；時區 Asia/Taipei；金額以「元」為單位、千分位。
8. 不要使用 emoji、漸層背景、左側色條卡片、Inter／Roboto／Arial。
9. 每頁在 360px 手機寬度下可用：側欄改為上方、表格橫向捲動、按鈕列自動換行。
10. 示意資料只放在 Storybook 或 Mock 中；正式頁面一律接 API，無資料時顯示空狀態。

## 1. 風格

「微科技人文感」：
- **人文**：米白紙感底色、標題用襯線體（Noto Serif TC）、問候式文案（例：「午安，今天一切運作平穩。」）、留白充足。
- **科技**：數據用等寬字、即時狀態點、影像格線、精準的狀態顏色。
- **克制**：一個重點色、細框線、無陰影或極淡陰影。

## 2. Design tokens

| 類別 | 變數 | 值 | 用途 |
| --- | --- | --- | --- |
| 底色 | `--pd-ground` | #F6F4EF | 頁面底 |
| 表面 | `--pd-surface` | #FFFFFF | 卡片 |
| 框線 | `--pd-line` | #E3DED4 | 卡片框 |
| 文字 | `--pd-ink` | #1E2A32 | 主文字 |
| 文字 | `--pd-muted` | #5B6670 | 標籤、說明（對比 ≥ 4.5:1） |
| 側欄 | `--pd-night` | #17232B | 側欄、登入頁左半 |
| 重點 | `--pd-accent` | #0F766E | 主要按鈕、選中、正常狀態 |
| 注意 | `--pd-warn` | #B45309 | 待處理、即將到期 |
| 緊急 | `--pd-danger` | #B42318 | 緊急事件 |
| 資訊 | `--pd-info-ink` | #344275 | 月租、處理中 |

字型：標題 Noto Serif TC 700、內文 Noto Sans TC 400/500、數據 JetBrains Mono 400/600。
字級：頁面標題 28px、區塊標題 20px、卡片標題 18px、內文 15px、表格 14px、標籤 13px、KPI 數字 40px（次要 28px）。
間距：4 的倍數（4／8／12／16／20／24／32／40）。卡片內距 20×22px，卡片間距 16px，頁面左右 32px。
圓角：按鈕與輸入框 10px、卡片 14px、手機卡片 16px、標籤膠囊 999px。

深色主題（`.pd-theme-night`）只用在「即時監控」這類長時間觀看的畫面。

## 5. 畫面清單與重點

| 畫面 | 路由 | 重點 |
| --- | --- | --- |
| 登入 | `/login` | 總部／自營／加盟共用入口；登入後 MFA |
| 營運總覽 | `/console` | 問候語、4 張 KPI、車道即時狀態卡、需要你注意、繳費機（未啟用時顯示預留卡） |
| 即時監控 | `/console/monitor` | 深色主題；每車道一格影像＋最近車牌＋柵欄／LED；跨站事件流；WebSocket 更新 |
| 例外處理 | `/console/incidents` | 左清單右詳情；認領、指派、修正車牌重新配對、對講、遠端開閘、結案；5 分鐘未認領升級 |
| 車輛進出紀錄 | `/console/sessions` | 4 個常用篩選＋快速篩選標籤；匯出 Excel |
| 月租管理 | `/console/monthly` | 固定／共用統計、到期提醒、候補；右側顯示本站月租規則 |
| 營收與車輛戰情板 | `/console/analytics` | 日／週／月／季切換＋自訂起訖；KPI、營收堆疊長條、付款方式占比、車流、場站排行、星期×時段熱力圖 |
| 手機版遠端開閘 | `/console/m/gate` | 4 步驟：選車道 → 看影像選原因 → MFA → 完成（等待雷達確認） |

## 6. 遠端開閘互動規格（桌面與手機一致）

1. 按「遠端開閘」開啟對話框（桌面）或進入步驟頁（手機）。
2. 必選原因：對講求助、付款問題、車牌誤判、設備故障、緊急狀況、其他（選「其他」必須填說明）。
3. 顯示該車道即時影像與最近車牌，避免開錯車道。
4. 送出前做 MFA；送出後顯示「指令 30 秒內有效」。
5. 結果頁顯示「柵欄已開啟，等待雷達確認車輛通過後自動結案」；逾時未執行顯示失敗並建立例外事件。
6. 後端對應 `gate_commands` 資料表與 `gate.remote_open` 權限。

## 7. 戰情板資料來源

| 圖表 | 來源 |
| --- | --- |
| KPI、營收趨勢、車流 | `daily_site_metrics`，週／月／季由後端彙總 |
| 付款方式占比 | `daily_site_metrics.revenue_by_method` |
| 場站排行 | `daily_site_metrics` 依 `site_id` 彙總；加盟主只回傳自己的站 |
| 熱力圖 | `parking_sessions.entry_at` 依星期與小時分組（快取 1 小時） |

圖表可用原生 SVG／CSS 繪製；若引入圖表套件，顏色必須使用 `--pd-chart-*` 變數，且提供文字替代（表格或 `aria-label`）。

## 8. 驗收

- 8 個畫面在 1440px 與 390px 寬度下與設計稿一致，無水平捲動（表格除外）。
- 所有互動元件可用 Tab 操作，焦點框清楚可見。
- 文字對比 ≥ 4.5:1。
- 現金繳費機在功能開關關閉時顯示預留卡，開啟後顯示存量卡。
